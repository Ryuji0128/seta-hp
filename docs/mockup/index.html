The Workshop · 工房について

一人で、
ひとつずつ。

昼はソフトウェアエンジニア、夜はカードディスプレイを作っています。 10年以上のMLBカードコレクターであり、400年の金工伝統がある富山県高岡市の小さな工房で、 SETA Craft を運営しています。

カタログにある全てのモデルは、私が設計・切削・造形・仕上げ・梱包まで一貫して行っています。 チームも外注もありません。レーザーと私と、「カードディスプレイはどうあるべきか」という 無数の判断だけがあります。
